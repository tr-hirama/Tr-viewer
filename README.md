# DXF / TRC ビューワー

ブラウザだけで動く、シンプルな **DXF** / **TRC（Tr-CAD 測量図面）** ファイルビューワーです。
ビルド不要・サーバー不要・外部ライブラリ不要・オフライン動作。`index.html` をブラウザで開くだけで使えます。

**🔗 ライブデモ: https://tr-hirama.github.io/Tr-viewer/**

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く
2. `.dxf` または `.trc` ファイルを画面に **ドラッグ&ドロップ**、または「ファイルを開く」から選択

拡張子（`.dxf` / `.trc`）で自動判別して表示します。
`sample.dxf` / `sample.trc` を読み込むと動作を確認できます。

### 操作

| 操作 | 動作 |
| --- | --- |
| マウスホイール | マウス位置を中心に拡大／縮小 |
| ドラッグ | 移動（パン） |
| ダブルクリック | 全体表示にリセット |
| マウス移動 | 右下にモデル座標 (X, Y) を表示 |

## DXF

対応エンティティ:
`LINE` / `LWPOLYLINE` / `POLYLINE`（旧形式 VERTEX） / `CIRCLE` / `ARC` / `POINT` / `TEXT` / `MTEXT`

- ASCII 形式の DXF に対応しています（バイナリ DXF は未対応）。
- Y 軸の上下反転、円弧の角度方向（DXF は反時計回り）を考慮して描画します。
- 未対応のエンティティは読み飛ばします。

## TRC（Tr-CAD 測量図面）

`cad-trcad`（vbSurvey）が出力する TRC ファイルを表示します。

- **実体は ZIP アーカイブ**で、内部に Shift-JIS の `TrDATA.trc` を格納しています（平文テキストの TRC も読めます）。
- ZIP の展開はブラウザ標準の `DecompressionStream` で行うため、**外部ライブラリは不要**です。
- `TrDATA.trc` は `*XXX-Section*` 〜 `*Section-End*` のセクション構造を持つ独自フォーマットです。

対応セクション:

| セクション | 内容 | 表示 |
| --- | --- | --- |
| `*Point-Section*` | 点（点名, X東, Y北, 非表示フラグ…） | 赤点＋点名 |
| `*Line-Section*` | 線（点名 pnA/pnB を参照して 2 点を結ぶ） | 青線（破線対応） |
| `*Circle-Section*` | 円（中心 X, Y, 半径） | 円 |
| `*Moji-Section*` | 文字（内容, 位置, 角度） | 文字 |
| `*Hedge-Section*` | 生垣ライン（2 点） | 緑線 |
| `*Pline-Section*` | ポリライン | 折れ線 |
| `*Block-Section*` / `*Insert-Section*` | 図枠などのブロックと配置 | 図枠 |

ヘッダーのチェックボックスで「線 / 点名 / 文字 / 図枠」の表示を切り替えられます。

- 座標系は測量座標（X=東, Y=北）で、画面では Y 軸を上向きに描画します。
- 線は点そのものではなく **点名（pnA / pnB）への参照**で保持されており、描画時に点座標を解決して結線します（Tr-CAD と同じ方式）。

## 今後の拡張候補

- DXF: レイヤーごとの色分け、`ELLIPSE` / `SPLINE` / `HATCH` / `DIMENSION`、`INSERT`（ブロック参照）展開
- TRC: ブロックの回転・倍率対応、画層（Layer）別の色分け、レベル / 測角データの表示、距離・面積計測
