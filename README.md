# DXF / TRC ビューワー

ブラウザだけで動く、シンプルな **DXF** / **TRC（測量座標点）** ファイルビューワーです。
ビルド不要・サーバー不要・オフライン動作。`index.html` をブラウザで開くだけで使えます。

**🔗 ライブデモ: https://tr-hirama.github.io/Tr-viewer/**

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く
2. `.dxf` または `.trc` ファイルを画面に **ドラッグ&ドロップ**、または「ファイルを開く」から選択

拡張子（`.dxf` / `.trc`）で自動判別して表示します。
`sample.dxf` / `sample.trc` を読み込むと動作を確認できます。

### 操作

| 操作 | 動作 |
| --- | --- |
| マウスホイール | マウス位置を中心に拡大／縮小 |
| ドラッグ | 移動（パン） |
| ダブルクリック | 全体表示にリセット |
| マウス移動 | 右下にモデル座標 (X, Y) を表示 |

## DXF

対応エンティティ:
`LINE` / `LWPOLYLINE` / `POLYLINE`（旧形式 VERTEX） / `CIRCLE` / `ARC` / `POINT` / `TEXT` / `MTEXT`

- ASCII 形式の DXF に対応しています（バイナリ DXF は未対応）。
- Y 軸の上下反転、円弧の角度方向（DXF は反時計回り）を考慮して描画します。
- 未対応のエンティティは読み飛ばします。

## TRC（測量座標点）

`cad-trcad`（vbSurvey）の TRC 形式に準拠した座標点ファイルを表示します。

- **書式**: 1 行 1 点。`点名, X(横/東), Y(縦/北), [Z 標高], [コード]`
- **区切り**: カンマ / タブ / 空白
- **コメント行**: `'` または `#` で始まる行は無視
- **文字コード**: Shift-JIS を優先（UTF-8 もフォールバック対応）

ヘッダーのチェックボックスで表示を切り替えられます:

| オプション | 内容 |
| --- | --- |
| 結線 | 点を入力順に線で結ぶ |
| コード表示 | 点名の後ろにコードを併記 |
| 点名表示 | 点名ラベルの表示／非表示 |

例（`sample.trc`）:

```
' 点名,X,Y,Z,コード
T1,100.000,200.000,12.5,基準点
T2,150.000,210.000,12.8,境界
```

## 今後の拡張候補

- DXF: レイヤーごとの色分け、`ELLIPSE` / `SPLINE` / `HATCH` / `DIMENSION`、`INSERT`（ブロック参照）展開
- TRC: コード別の色分け・記号、面積/距離の計測、CSV/SIMA など他形式の取り込み
